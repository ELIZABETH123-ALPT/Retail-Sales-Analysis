# Retail Sales Analysis using MySQL

## Project Overview

This project analyzes retail sales data using MySQL. It demonstrates SQL skills through a series of queries covering basic data retrieval, sales analysis, joins, subqueries, CTEs, stored procedures, and window functions.

## Database Structure

The project contains three main tables:

- `customer_details` – customer information
- `product_details` – product information
- `order_details` – order and sales information

## SQL Skills Demonstrated

- Database and table creation
- Data insertion
- SELECT, WHERE, ORDER BY, LIMIT
- DISTINCT and filtering
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- INNER JOIN and other joins
- Subqueries
- CASE statements
- Common Table Expressions (CTEs)
- Stored Procedures
- Date-based analysis
- Window functions
- RANK() and DENSE_RANK()

## Project Analysis

The queries cover different retail sales analysis tasks, including:

- Customer and product analysis
- Total and average sales
- Sales by product and customer
- Filtering and grouping sales data
- Identifying top-performing products and customers
- Date-based sales analysis
- Ranking products and customers
- Advanced SQL analysis using CTEs and window functions

## Tools Used

- MySQL
- MySQL Workbench

## Project Structure

The SQL files are organized into sections covering:

1. Database Setup and Data
2. Basic Queries
3. GROUP BY and HAVING
4. Joins and Sales Analysis
5. Subqueries
6. CASE and CTE

## Dataset

The dataset contains:

- 5 customers
- 5 products
- 8 orders

## Purpose

The goal of this project is to demonstrate practical SQL skills for data analysis and build a portfolio project suitable for a Data Analyst role.
